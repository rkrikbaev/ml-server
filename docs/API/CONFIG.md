# Конфигурация

## Redis

| Название переменной | Описание переменной                    | Значение по умолчанию  |
| ------------------- | -------------------------------------- | ---------------------- |
| **REDIS_URL**       | URL Redis сервера                      | "redis://redis:6379/0" |
| **REDIS_TIMEOUT**   | Таймаут подключения к Redis в секундах | 3600                   |

## NDC

| Название переменной | Описание переменной           | Значение по умолчанию                         |
| ------------------- | ----------------------------- | --------------------------------------------- |
| **NDC_HOSTS**       | Список хостов к доступу в НДЦ | ["10.210.1.11", "10.210.1.13", "10.210.1.15"] |
| **NDC_URLS**        | Список URL к доступу в НДЦ    | ["http://{NDC_HOSTS}:7080/api/read/archive"]  |

## RZ

| Название переменной | Описание переменной     | Значение по умолчанию                            |
| ------------------- | ----------------------- | ------------------------------------------------ |
| **RZ_URL**          | URL к доступу в ремонты | Получают из `.env` файла переменной `RZ_API_URL` |

## General

| Название переменной     | Описание переменной                          | Значение по умолчанию                |
| ----------------------- | -------------------------------------------- | ------------------------------------ |
| **HEADERS**             | Заголовки для доступа к API                  | {"Content-Type": "application/json"} |
| **CLIENT_TIMEOUT_ONE**  | Таймаут в секундах для одного запроса к API  | 30                                   |
| **CLIENT_TIMEOUT_ALL**  | Таймаут в секундах для всех запросов к API   | `CLIENT_TIMEOUT_ONE` умножаем на 5   |
| **GMT_TO_ASTANA_HOURS** | Часовой пояс GMT относительно Астаны в часах | 5                                    |

## Tag

| Название переменной    | Описание переменной                                                                 | Значение по умолчанию |
| ---------------------- | ----------------------------------------------------------------------------------- | --------------------- |
| **TAG_PREDICT_CREATE** | Тэг для API [**predict** схемы](./schema/PREDICT.md#создание-predictcreateschema)   | "predict_create"      |
| **TAG_PREDICT_UPDATE** | Тэг для API [**predict** схемы](./schema/PREDICT.md#обновление-predictupdateschema) | "predict_update"      |

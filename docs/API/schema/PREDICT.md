# Схема для Predict

Для [API predict](../MAIN.md#1-predict) было разделено на 2 важные части:
1. [Создание](#создание-predictcreateschema) - 1-ый запрос
2. [Обновление](#обновление-predictupdateschema) - 2-ой запрос

На каждой схеме действует строгий режим и чужие поля не нравятся

## Создание `PredictCreateSchema`

|                    | Название Поля              | Тип Данных   | Значения по умолчанию         |
| ------------------ | -------------------------- | ------------ | ----------------------------- |
| **не обязательно** | model_path                 | string       | "none"                        |
|                    | step                       | integer      | 3600                          |
|                    | output_range               | integer      | 1                             |
|                    | clip_negatives_to_0        | boolean      | True                          |
|                    | use_dynamic_normalization  | boolean      | False                         |
|                    |                            |              |                               |
| **обязательно**    | archives                   | List[string] |                               |
|                    | fp_path                    | string       |                               |
|                    |                            |              |                               |
| **внутри**         | mode                       | string       | устанавливается автоматически |
|                    | online                     | boolean      | устанавливается автоматически |

---

### Не обязательные поля

---

#### model_path

Если **model_path** пустое, то выведет ошибку: `'model_path' must be non-empty`

---

#### step

> После установки умножается на 1000, чтобы превратить секунды в миллисекунды

Если меньше или равно 0, то выведет ошибку: `'step' must be greater than 0`

---

#### output_range

> После установки умножается на 3600000 и делится на **step**

Если меньше или равно 0, то выведет ошибку: `'output_range' must be greater than 0`

---
---
---

### Обязательные поля

---

#### archives

Если **archives** пустое, то выведет ошибку: `'archives' must be non-empty`

---

#### fp_path

Если **fp_path** пустое, то выведет ошибку: `'fp_path' must be non-empty`

Если **fp_path** не содержит `/` или `\`, то выведет ошибку: `'fp_path' must contain '/' or '\'`

---
---
---

### Внутренние поля

> Внутренние поля изменить внешне нельзя

---

#### mode

| Режим     | Описание                                  |
| --------- | ----------------------------------------- |
| **day**   | поле **step** меньше 86400000             |
| **month** | поле **step** между 86400000 и 2419200000 |
| **year**  | поле **step** больше или равно 2419200000 |

---

#### online

| Режим     | Описание                            |
| --------- | ----------------------------------- |
| **True**  | поле **model_path** равно "none"    |
| **False** | поле **model_path** не равно "none" |

---

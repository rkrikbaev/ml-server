# Брокер

Брокер использует очередь задач для распределения нагрузки между несколькими Workers. Хранит результаты в Redis максимум на 1 час.

> Логика хранится в папке `tasks`.

## `predict`

Используется в [API](../MAIN.md#1-predict). Добавляет задачу в очередь и возвращает ID задачи. Когда задача выполнится из Redis достанет результат и выдаст по ID задачи (пока время до 1-ого часа позволяет).

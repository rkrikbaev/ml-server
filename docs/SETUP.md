# 1-ая установка

## Шаги

```bash
$ # 1. Из файла '.env.example' создайте файл '.env' со своими настройками
$
$ # 2. Соберите контейнер
$ docker buildx build --ssh default --load -t fpcloud/ml:1.0.0 -f ./docker/Dockerfile .
$
$ # 3. Запустите контейнер
$ docker compose -f docker/docker-compose.yaml up -d
```

## Предупреждения

### 2-ой пункт от шага

Внутри вшито пакетирование ветки **package** из репозитория **oik-new**.\
Пакет содержит `fpforecast` — код для прогнозирования.

### 3-ий пункт от шага

Код от папки с `api` не входит в контейнер. Docker Compose читает самостоятельно из файловой системы компьютера, а не своей файловой системы. Если файлы `api` поменяются, тогда нужно остановить контейнер и запустить заново. Контейнер не понимает режим реального времени и изменёные файлы не ловит!

## Какие контейнеры запустятся?

Запустятся 2 контейнера: **API** и **Redis**. **API** запускает брокер и API-сервер по порту 8000 (порт не внешний, а внутренний - внешний указан в файле `.env`).
